# واجهة تحليل تعليقات جمهور خطيرة

واجهة ويب لمشروع تحليل تعليقات الجمهور على حسابات خطيرة (يوتيوب وإنستجرام وفيسبوك، وTikTok وX اختيارياً).

- افتح الواجهة من رابط GitHub Pages الخاص بهذا المستودع.
- سجّل الدخول باسم مستودع المحرك (`اسم-الحساب/khateera-audience-comments`) ومفتاح وصول GitHub من نوع Fine-grained.
- مفتاح الوصول يُحفظ في متصفحك فقط، ولا يُرسل إلا إلى GitHub.
